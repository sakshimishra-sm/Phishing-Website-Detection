## Project Overview

This project applies supervised machine learning to automatically detect phishing websites.
A **Random Forest classifier** is trained on 30 URL and web-page structural features from
the UCI Phishing Websites Dataset (11,055 records) to classify websites as either
**Phishing** or **Legitimate**.

The project demonstrates how machine learning can assist in cybersecurity by learning
discriminative patterns from thousands of labelled examples and generalising to new,
unseen websites.

> **Disclaimer:** The model produces probabilistic estimates — it can produce false positives
> (legitimate sites flagged as phishing) and false negatives (phishing sites missed).
> It must not be used as the sole security measure.

---

## Problem Statement

Phishing attacks remain one of the top cybersecurity threats globally. Manual defences
(URL blacklists, rule-based filters) are reactive, brittle, and cannot scale to the
millions of new phishing sites created every day. This project builds an automated,
data-driven classifier that learns from known examples to flag suspicious websites.

## Dataset Description

**Name:** Phishing Websites Dataset  
**Source:** [UCI Machine Learning Repository — ID 327](https://archive.uci.edu/dataset/327/phishing+websites)  
**Records:** 11,055 website records  
**Features:** 30 input features + 1 target variable (`Result`)  
**Task:** Binary Classification

### Feature Encoding

Most features use a 3-value encoding:

| Value | Meaning |
|---|---|
| `-1` | Phishing indicator (suspicious/bad sign) |
| `0` | Suspicious / neutral |
| `1` | Legitimate indicator (good sign) |

### Target Variable: `Result`

| Value | Class |
|---|---|
| `-1` | **Phishing** |
| `1` | **Legitimate** |

## Model Evaluation Metrics

| Metric | Description |
|---|---|
| Accuracy | Overall % of correct predictions |
| Precision | % of phishing predictions that are actually phishing |
| Recall | % of actual phishing sites that are detected |
| F1-Score | Harmonic mean of Precision and Recall |
| Confusion Matrix | TP / FP / TN / FN breakdown |

> Exact values are generated when the notebook is executed. Typical performance
> on this dataset with Random Forest is approximately **97% accuracy**.

## Limitations and Responsible Use

- **Not a live scanner:** The model classifies pre-extracted feature vectors, not live URLs.
- **False negatives are possible:** Some phishing sites will not be detected.
- **Static dataset:** Trained on ~2012 data; modern phishing tactics may differ.
- **Use defensively only:** Never use this system to assist in creating or evading phishing detection.
- **Multi-layer security:** Always combine ML predictions with blacklists, user education,
  and other security controls.
